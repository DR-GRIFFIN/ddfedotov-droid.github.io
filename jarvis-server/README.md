# Сервер Джарвиса

Джарвис живёт на домашнем Mac (oldmac) и отвечает с Apple Watch, iPhone и веб-страницы.

```
Часы / iPhone / веб-страница
        │  HTTPS + ключ доступа
        ▼
Tailscale Funnel  (https://oldmac.….ts.net)
        │
        ▼
Mac: сервер Джарвиса ──► Claude API (Haiku 5.5)
        │
        ├── термостат Ecobee   (через «Дом» и «Команды» на Mac)
        ├── камеры Blink       (blinkpy)
        ├── статистика сети    (замеры с самого Mac)
        ├── файлы на Mac       (только чтение, только выбранные папки)
        └── память             (общая для часов, телефона и страницы)
```

## Установка (≈10 минут)

Нужно: Mac с macOS 12 или новее, ключ Claude API (console.anthropic.com → API Keys), Tailscale.

```bash
cd ~
git clone https://github.com/DR-GRIFFIN/ddfedotov-droid.github.io.git jarvis-repo
cd jarvis-repo/jarvis-server
./install.sh
```

Установщик:
1. Записывает, что уже работает на Mac, в `~/.jarvis/system-report.txt`. Этот отчёт можно прислать Claude.
2. Ставит Python 3.12 и библиотеки в папку `.venv`. Системный Python не трогает.
3. Спрашивает ключ Claude API и папки, которые Джарвису можно читать, и создаёт `~/.jarvis/config.toml`.
4. Включает автозапуск: сервер стартует при входе в систему и перезапускается после сбоя.
5. По желанию открывает доступ снаружи через Tailscale Funnel.
6. Показывает **ключ доступа**. Он понадобится для часов и веб-страницы.

### Чтобы сервер работал круглосуточно

- **Сон.** Выполните один раз: `sudo pmset -a sleep 0 disksleep 0`. Если крышка будет закрыта, добавьте `sudo pmset -a disablesleep 1`.
- **Автовход.** Сервер запускается, когда вы вошли в систему: термостат работает через «Команды», а им нужен ваш сеанс. Включите автовход: «Системные настройки» → «Пользователи и группы» → «Автоматический вход». Если там его нет, отключите FileVault.
- **Батарея.** Ноутбук, который всегда на зарядке, рискует получить вздутую батарею. Включите «Оптимизированную зарядку» и раз в пару месяцев проверяйте, не приподнялся ли тачпад.

## Управление

```
./jarvis.sh status        работает ли
./jarvis.sh logs          журнал
./jarvis.sh restart       после изменения ~/.jarvis/config.toml
./jarvis.sh doctor        проверка настроек
./jarvis.sh ask "Как интернет сегодня?"
./jarvis.sh key           показать ключ доступа (--new — сменить)
./jarvis.sh update        обновить из GitHub
```

## Подключения

| Что | Как включить | Инструкция |
|---|---|---|
| Часы и iPhone | Команда «Джарвис» в «Командах» | [docs/watch.md](docs/watch.md) |
| Доступ снаружи | `./jarvis.sh funnel` | [docs/tailscale.md](docs/tailscale.md) |
| Термостат Ecobee | Три команды на Mac, `[thermostat] enabled = true` | [docs/ecobee.md](docs/ecobee.md) |
| Камеры Blink | `./jarvis.sh blink-login`, `[blink] enabled = true` | [docs/blink.md](docs/blink.md) |
| Уведомления | Тема ntfy в `[notify]` | [docs/notifications.md](docs/notifications.md) |
| Веб-страница | «Настройки» → адрес сервера и ключ | `../jarvis/README.md` |

Сеть отслеживается сразу после установки:
- проверка связи раз в минуту;
- замер скорости раз в час (≈35 МБ трафика за замер, около 25 ГБ в месяц; реже — `speedtest_every_min`);
- поиск новых устройств раз в 10 минут.

Учтите: скорость меряется на самом Mac. Если он подключён по Wi-Fi, результат упирается в Wi-Fi, а не в тариф Rogers. Для честных замеров подключите Mac кабелем.

## Безопасность

- **Сервер слушает только `127.0.0.1`.** Из домашней сети напрямую к нему не подключиться, только через Tailscale.
- **Каждый запрос требует ключ доступа.** После 10 неверных попыток адрес блокируется на 15 минут.
- **Секреты хранятся только на Mac.** Ключ Claude API, ключ доступа и токены Blink лежат в `~/.jarvis` (права 600) и в репозиторий не попадают.
- **Файлы только на чтение** и только в папках из `[files] folders`. Выйти за них через `..` или ссылки нельзя.
- **Снять камеры с охраны** можно только после подтверждения в следующей реплике.
- **Термостат ограничен диапазоном** `min_c`–`max_c`.
- **Что уходит в Anthropic.** Вопросы и то, что Джарвис прочитал для ответа: снимки с камер, фрагменты файлов, данные о сети. Всё это отправляется в Claude API. Если какие-то камеры так использовать не нужно, перечислите разрешённые в `allowed_cameras`.

## Стоимость

Haiku 5.5 стоит $0.10 за миллион входящих токенов и $0.50 за миллион исходящих. Обычный вопрос с историей разговора — это доли цента. Вопрос со снимком камеры чуть дороже, около цента. Расход виден в console.anthropic.com → Usage.
