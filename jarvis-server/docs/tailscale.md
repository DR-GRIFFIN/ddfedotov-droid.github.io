# Доступ снаружи: Tailscale Funnel

Сервер Джарвиса слушает только сам Mac (`127.0.0.1`). Tailscale Funnel даёт ему постоянный адрес `https://oldmac.ВАШ-TAILNET.ts.net`. Так до сервера достучатся:
- часы по LTE без телефона;
- iPhone вне дома;
- веб-страница.

Что даёт Funnel:
- порты на роутере Rogers открывать не нужно;
- HTTPS-сертификат Tailscale выпускает сам;
- без ключа доступа сервер ни на что не отвечает, только `/health` скажет «ok».

## Включить

```bash
./jarvis.sh funnel
```

При первом включении Tailscale может показать ссылку, чтобы разрешить HTTPS и Funnel для вашей сети (tailnet) в панели управления login.tailscale.com. Откройте её, разрешите и повторите команду.

В выводе будет адрес вида:

```
https://oldmac.tail1234.ts.net (Funnel on)
|-- / proxy http://127.0.0.1:8765
```

Этот адрес и ключ из `./jarvis.sh key` вписываются в команду на часах и в настройки веб-страницы.

Если порт 443 в Tailscale уже занят чем-то другим на этом Mac, скрипт возьмёт 8443. Тогда адрес будет с `:8443` на конце.

## Проверить снаружи

С телефона с выключенным Wi-Fi откройте `https://ВАШ-АДРЕС.ts.net/health`. Должно показаться `{"ok": true, …}`.

## Выключить

```bash
./jarvis.sh funnel-off
```

Внутри вашей сети Tailscale (с устройств, где он установлен) сервер всё равно будет доступен по `tailscale serve`. Снаружи — нет.

## Если ключ доступа утёк

```bash
./jarvis.sh key --new
./jarvis.sh restart
```

После этого обновите ключ в команде на часах и на веб-странице.
