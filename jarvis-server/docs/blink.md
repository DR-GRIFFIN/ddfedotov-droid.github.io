# Камеры Blink

Подключение идёт через **blinkpy**: неофициальную библиотеку, на которой работает интеграция Blink в Home Assistant. Официального API у Blink нет. Если Amazon что-то поменяет у себя, функции могут временно перестать работать, пока библиотеку не обновят. Обновление: `./jarvis.sh update`.

## Вход (один раз)

```bash
./jarvis.sh blink-login
```

1. Введите e-mail и пароль от Blink. Пароль при вводе не отображается.
2. Blink пришлёт код по SMS или на почту. Введите его.
3. Сохраняются только токены входа: `~/.jarvis/blink-credentials.json`, права 600. Пароль не сохраняется.

Затем в `~/.jarvis/config.toml`:

```toml
[blink]
enabled = true
allowed_cameras = []   # пусто = все камеры
```

И выполните `./jarvis.sh restart`.

**Если какие-то камеры не надо показывать Claude** (например, внутри дома), перечислите только разрешённые:

```toml
allowed_cameras = ["Входная дверь", "Двор"]
```

Названия должны совпадать с названиями в приложении Blink. Остальные камеры Джарвис не видит.

## Что умеет

| Скажите | Что произойдёт |
|---|---|
| «Кто у двери?» | Свежий снимок с камеры (5–10 секунд), Claude описывает, что на нём. На часах снимок показывается, если вы добавили шаг из docs/watch.md. |
| «Что было ночью?» | Список записей движения. Можно попросить «покажи» — Джарвис возьмёт превью последних записей. |
| «Поставь на охрану» | Ставит сразу. |
| «Сними с охраны» | Сначала спросит «Точно?». Сработает, только если вы подтвердите следующей фразой. |
| «Как батарейки у камер?» | Заряд, сигнал Wi-Fi, температура у камеры. |

## Флешка в Sync Module 2 (без подписки)

Если в Sync Module 2 вставлена флешка, записи движения хранятся на ней, и подписка Blink не нужна. Джарвис видит список таких записей: «что было ночью?» работает, в ответе будет пометка «флешка».

Важно знать:
- **Превью записей с флешки Джарвис не показывает:** Blink не делает для них картинок. Свежий снимок по запросу («кто у двери?») работает как обычно.
- **Новые камеры и дверной звонок** можно добавить к тому же Sync Module 2 в приложении Blink («+» → устройство → выбрать существующую систему). Тогда их записи тоже пойдут на флешку.
- **Связь идёт через облако Blink.** Джарвис не подключается к модулю напрямую по домашней сети: у Sync Module нет локального API. Поэтому интернет дома нужен.

## Ограничения

- **Видеотрансляции нет:** только снимки и превью записей.
- **Снимок тратит заряд.** Каждый снимок будит камеру и немного расходует батарейки.
- **Снимки уходят в Anthropic.** Чтобы описать снимок, Claude его получает. Людей Джарвис описывает по внешнему виду и не пытается узнать, кто это.
- **Снова просит код.** Если Blink запросит код ещё раз (бывает раз в несколько месяцев или после смены пароля), Джарвис скажет: «нужно войти заново». Повторите `./jarvis.sh blink-login`.
