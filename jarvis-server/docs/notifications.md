# Уведомления на iPhone и часы (необязательно)

Джарвис может сам сообщать о событиях:
- **интернет вернулся после обрыва**, с длительностью обрыва;
- **в сети появилось новое устройство.**

Без уведомлений эти события всё равно записываются, и о них можно спросить: «Что нового в сети?»

Уведомления приходят через бесплатный сервис **ntfy**.

1. Установите на iPhone приложение **ntfy** из App Store.
2. Придумайте длинную случайную тему. Кто знает тему, тот видит уведомления. Сгенерировать её можно так:
   ```bash
   python3 -c "import secrets; print('jarvis-' + secrets.token_hex(12))"
   ```
3. В приложении ntfy подпишитесь на эту тему (сервер по умолчанию `ntfy.sh`).
4. В `~/.jarvis/config.toml`:
   ```toml
   [notify]
   ntfy_topic = "jarvis-…ваша тема…"
   ```
5. Выполните `./jarvis.sh restart`.

Уведомления iPhone автоматически дублируются на Apple Watch.

**Про приватность.** Тексты уведомлений проходят через сервер ntfy.sh. В них только сообщения вида «Интернет пропадал 12 минут» или «Новое устройство: 192.168.0.23». Если не хочется пускать их через чужой сервер, ntfy можно поднять у себя и указать его адрес в `ntfy_server`.
