# Чеки покупок (Costco и другие)

Джарвис отвечает на вопросы вроде:
- «За сколько я покупал огурцы в Costco последний раз?»
- «Сколько я потратил в Costco за месяц?»

Для этого он читает чеки из папки на Mac.

```
Ваша выгрузка чеков (PDF) → Google Drive → Google Drive для компьютера на oldmac
   → Джарвис раз в 30 минут находит новые файлы → Claude разбирает строки → база на Mac
```

## 1. Google Drive для компьютера на oldmac

1. Скачайте **Google Drive для компьютера**: google.com/drive/download. Установите и войдите в тот Google-аккаунт, куда выгружаются чеки.
2. В Finder появится раздел **Google Drive**. Найдите там папку с чеками.
3. Правый клик по папке → **«Доступно офлайн»** (Available offline). Так файлы будут скачиваться сразу, а не по запросу.

Узнать полный путь к папке можно так: перетащите её в окно Терминала. Путь будет примерно такой:

```
/Users/ИМЯ/Library/CloudStorage/GoogleDrive-ваш@gmail.com/My Drive/Costco
```

## 2. Включить в Джарвисе

В `~/.jarvis/config.toml`:

```toml
[purchases]
enabled = true
folder = "/Users/ИМЯ/Library/CloudStorage/GoogleDrive-ваш@gmail.com/My Drive/Costco"
scan_every_min = 30
```

Затем:

```bash
./jarvis.sh restart
./jarvis.sh receipts      # загрузить все чеки сейчас и показать итог
./jarvis.sh ask "За сколько я покупал огурцы в Costco последний раз?"
```

При первом запуске macOS может спросить, можно ли Python читать файлы Google Drive. Разрешите.

## Как это устроено

- **Форматы:** PDF, JPG, PNG, WebP, во всех подпапках. Фото чеков с телефона, сохранённые в ту же папку, тоже подхватятся.
- **Разбор:** каждый новый файл один раз разбирает Claude (Haiku). Он переводит сокращения чека в понятные названия на английском и русском, например «KS MINI CUCUMBR» → «мини-огурцы Kirkland», чтобы можно было спросить по-русски. Скидки (TPD, Instant Savings) отмечаются отдельно и в цену товара не попадают.
- **Повторы:** чек, выгруженный ещё раз (тот же магазин, дата и сумма), не задваивается.
- **Стоимость:** разбор одного чека — доли цента.
- **Хранение:** строки чеков хранятся в базе `~/.jarvis/jarvis.db` на Mac. В Anthropic файл уходит один раз, при разборе. Сами PDF остаются в Google Drive, Джарвис их не меняет и не удаляет.

## Если что-то не так

`./jarvis.sh receipts` покажет, сколько файлов найдено, сколько загружено, и последние ошибки.

- **«файлов-кандидатов: 0»** — неверный путь, или Google Drive не запущен, или файлы ещё не скачались (включите «Доступно офлайн»).
- **Чек не находится по слову** — спросите иначе или по-английски: «cucumber», «milk».
- **Чек разобрался с ошибкой** — пришлите Claude пример файла, подгоним разбор.
