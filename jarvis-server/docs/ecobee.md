# Термостат Ecobee

У Ecobee нет открытого API для новых разработчиков, поэтому термостат подключается через Apple Home.

```
Джарвис → утилита shortcuts на Mac → «Команды» → «Дом» → Ecobee
```

## 1. Добавить Ecobee в «Дом»

1. На термостате откройте меню → **Settings** (Настройки) → **HomeKit**. Там показан код подключения.
2. На iPhone откройте приложение «Дом» → «+» → «Добавить аксессуар» и отсканируйте код с экрана термостата.
3. Назовите термостат, например «Термостат», и выберите комнату.

Mac должен быть под тем же Apple ID, что и iPhone. Тогда термостат появится и в приложении «Дом» на Mac. Проверьте: откройте «Дом» на oldmac и поменяйте температуру, она должна измениться.

## 2. Создать три команды на Mac

Создавайте команды на **oldmac** в приложении «Команды». Названия должны совпадать **точно**, буква в букву.

### «Джарвис термостат статус»

Нужно вернуть текст вроде «В доме 20,5°, цель 21°, режим обогрев, влажность 40%».

1. **«Получить состояние»** аксессуара (Get State of Home accessory) → «Термостат» → «Текущая температура».
2. Ещё раз то же действие → «Целевая температура».
3. Ещё раз → «Целевой режим обогрева/охлаждения» (если такого пункта нет, пропустите).
4. Ещё раз → «Текущая влажность» (если есть).
5. **«Текст»** (Text): `В доме [Текущая температура]°, цель [Целевая температура]°, режим [Режим], влажность [Влажность]%`. Значения в скобках — это переменные из шагов 1–4.
6. **«Остановить и вывести»** (Stop and Output) → «Текст».

### «Джарвис термостат температура»

Получает на вход число (например, `21`) и ставит его целевой температурой.

1. В настройках команды включите «Получать ввод» → тип **Текст**.
2. **«Получить числа из ввода»** (Get Numbers from Input) → «Ввод команды».
3. **«Управлять домом»** (Control Home) → «Термостат» → «Целевая температура» → вместо числа выберите переменную «Числа».

**Если поле не принимает переменную**, сделайте через «Если»:
- **«Если»** «Числа» равно 20 → «Управлять домом» → 20°;
- «Иначе если» 20,5 → 20,5°;
- и так далее для нужных значений, например от 18 до 24.

Это длиннее, но тоже работает. Сервер всё равно округляет до 0,5° и не выходит за диапазон `min_c`–`max_c` из настроек.

### «Джарвис термостат режим»

Получает на вход `heat`, `cool`, `auto` или `off`.

1. «Получать ввод» → Текст.
2. **«Если»** «Ввод команды» **равно** `heat` → «Управлять домом» → «Термостат» → режим «Обогрев».
3. «Иначе если» `cool` → «Охлаждение»; `auto` → «Авто»; `off` → «Выкл.».

## 3. Проверить в Терминале

```bash
shortcuts run "Джарвис термостат статус"
echo 21 > /tmp/t.txt && shortcuts run "Джарвис термостат температура" --input-path /tmp/t.txt
```

При первом запуске macOS спросит разрешение на доступ к «Дому». Разрешите.

## 4. Включить в Джарвисе

В `~/.jarvis/config.toml`:

```toml
[thermostat]
enabled = true
min_c = 16
max_c = 26
```

Затем выполните `./jarvis.sh restart` и `./jarvis.sh doctor`: все три команды должны быть ✅.

Попробуйте: `./jarvis.sh ask "Сколько сейчас градусов дома?"`

## Если не работает

- **«нет команды …»** — название не совпадает буква в букву. Проверьте: `shortcuts list`.
- **Команда работает в Терминале, но не из сервера.** Сервер запущен из-под вашего пользователя и видит те же команды. Проверьте, что вы вошли в систему: нужен автовход.
- **Mac не видит термостат.** Убедитесь, что Mac под тем же Apple ID, что и «Дом» на iPhone, и что в «Системных настройках» → «Конфиденциальность» у «Команд» есть доступ к «Дому».
