# Джарвис на Apple Watch и iPhone

Это делается через приложение «Команды» (Shortcuts) на iPhone. Команда сама появится на часах. Публиковать что-то в App Store не нужно.

Понадобятся:
- **адрес сервера** — `https://oldmac.….ts.net` из `./jarvis.sh funnel`;
- **ключ доступа** — из `./jarvis.sh key`.

Названия действий ниже даны для русского интерфейса iOS, в скобках — английские. В вашей версии iOS они могут немного отличаться: ищите по смыслу в поиске действий.

## 1. Создать команду «Джарвис»

На iPhone откройте «Команды» → «+». Назовите команду **Джарвис**. По этому имени её будет запускать Siri: «Привет, Siri, Джарвис».

Добавьте действия по порядку:

1. **«Продиктовать текст»** (Dictate Text).
   - Язык: русский.
   - «Прекратить слушать»: «После паузы».
2. **«Получить содержимое URL»** (Get Contents of URL).
   - URL: `https://ВАШ-АДРЕС.ts.net/api/ask`
   - Метод: **POST**.
   - Заголовки: ключ `Authorization`, значение `Bearer ВАШ-КЛЮЧ` (слово Bearer, пробел, ключ).
   - Тело запроса: **JSON** с двумя полями:
     - `text` (текст) — выберите переменную «Продиктованный текст»;
     - `source` (текст) — `watch`.
3. **«Получить значение из словаря»** (Get Dictionary Value): ключ `reply`, словарь — «Содержимое URL».
4. **«Произнести текст»** (Speak Text): «Значение из словаря».
5. **«Показать результат»** (Show Result): «Значение из словаря». Ответ останется текстом на экране часов.

Откройте настройки команды (значок ⓘ) и включите **«Показывать на Apple Watch»**.

## 2. Проверка

- На iPhone: нажмите на команду и скажите «Какая погода дома?» Джарвис ответит, что поможет с термостатом, когда тот будет подключён.
- На часах: «Привет, Siri, Джарвис» или приложение «Команды» → «Джарвис».

Если в ответ приходит ошибка:
- `401` — неверный ключ (проверьте слово `Bearer` и пробел после него);
- `429` — было больше 10 неверных попыток, подождите 15 минут;
- не отвечает совсем — проверьте `./jarvis.sh status` на Mac и `./jarvis.sh funnel`.

## 3. Удобства

- **Значок на циферблате.** Долгое нажатие на циферблат → «Править» → выберите место для расширения → «Команды» → «Джарвис». Тогда достаточно одного касания.
- **Кнопка «Действие»** (Apple Watch Ultra): «Настройки» → «Кнопка „Действие“» → «Команда» → «Джарвис».
- **Продолжение разговора.** Добавьте в конец **«Выбрать из меню»** (Choose from Menu) с пунктами «Ещё» и «Готово». В ветку «Ещё» поставьте **«Запустить команду»** → «Джарвис». Джарвис помнит контекст, поэтому можно говорить коротко: «А сделай ещё на градус теплее».
- **Снимки с камер.** Когда Джарвис делает снимок, в ответе есть поле `image` (картинка в base64). После шага 5 добавьте:
  1. «Получить значение из словаря» с ключом `image`;
  2. «Если» (If) — значение «имеет любое значение»;
  3. внутри: «Декодировать Base64» (Base64 Decode) → «Показать результат» или «Быстрый просмотр» (Quick Look).

## 4. iPhone

Та же команда работает на iPhone:
- «Привет, Siri, Джарвис»;
- виджет «Команды» на экране «Домой»;
- кнопка «Действие» на iPhone 15 Pro и новее.

Можно сделать отдельную копию с `source` = `phone`, чтобы в истории было видно, откуда пришёл вопрос.

## Про LTE

Пока iPhone рядом, часы ходят в интернет через него. Без телефона часы с LTE ходят сами, и как раз поэтому сервер открыт через Tailscale Funnel: адрес `….ts.net` доступен откуда угодно. Без ключа доступа он не отвечает.
