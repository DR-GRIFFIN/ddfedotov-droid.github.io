# Orléans Fitness: экраны MVP

Дополняет [CONCEPT.md](CONCEPT.md). Описано, что есть на каждом экране и как экраны связаны. Визуальный стиль пока не выбран.

## Навигация

Нижняя панель из 5 вкладок:

| Вкладка | Что внутри |
|---|---|
| **Сегодня** | Главная: тренировка дня, неделя, питание вкратце |
| **Программа** | Текущая программа, каталог программ, упражнения |
| **Питание** | Еда за день, вес |
| **Прогресс** | Возвращения, графики, недельный итог |
| **Друзья** | Активность друзей, «пинки» |

Профиль и настройки открываются по аватару в правом верхнем углу.

## Основной сценарий

```
Вход → Анкета → (Стоп-экран здоровья) → Рекомендация → Сегодня
Сегодня → Отметка самочувствия → Обзор тренировки → Упражнение ×N → Итог тренировки
Следующее утро: Сегодня → «Как спина/суставы?» (светофор)
```

## 1. Вход и настройка

### 1.1 Приветствие
- Название, одна фраза: «Первый год в зале — без травм и без бросаний».
- Переключатель языка RU / EN.
- Кнопки «Войти через Google» и «Войти по email» (ссылка на почту, без пароля).

### 1.2 Анкета
Один вопрос на экран, сверху полоса прогресса, всего ~8 шагов. На каждом шаге есть «Назад».

1. Имя, возраст, рост, вес.
2. Опыт в зале: никогда / меньше 3 месяцев / был перерыв.
3. Цель: похудеть / рекомпозиция / набор / поддержание.
4. Сколько раз в неделю и сколько минут.
5. Где тренируется: обычный зал / маленький зал или только гантели.
6. Активность вне зала: сидячая / средняя / высокая (нужна для расчёта калорий).
7. **Здоровье**: да/нет на вопросы о сердце, давлении, обмороках, недавних операциях и травмах.
8. **Боли и ограничения**: схема тела, на ней отмечаются зоны (спина, колени, плечи…) и сила боли сейчас.

### 1.3 Стоп-экран здоровья
Появляется, если в шаге 7 есть «да» или в шаге 8 сильная боль.
- Спокойный текст: «Перед началом лучше показаться врачу».
- Список ответов, из-за которых появился экран.
- Кнопки:
  - «Врач разрешил», с подтверждением;
  - «Вернусь позже».
- Без подтверждения тренировки недоступны. Питание при этом работает.

### 1.4 Рекомендация
- AI советует программу, например «Старт — 3 раза в неделю». Под ней 1–2 строки, почему.
- Если в анкете отмечена спина, AI предлагает «Бережную к спине».
- Цели питания: калории и белок, их можно поправить.
- Кнопки «Начать» и «Выбрать другую программу» (ведёт в каталог 3.2).
- Напоминание, что первые 2 недели — неделя техники.

## 2. Сегодня (главная)

```
┌─────────────────────────────┐
│ Привет, Дима           (👤) │
│                             │
│ Неделя:  ● ● ○   2 из 3     │
│ Возвращений: 4 ↩            │
│                             │
│ ┌─────────────────────────┐ │
│ │ Тренировка B · ~50 мин  │ │
│ │ Гоблет-присед, Тяга...  │ │
│ │ [ Начать тренировку ]   │ │
│ └─────────────────────────┘ │
│                             │
│ Питание  1450 / 2100 ккал   │
│          ▓▓▓▓▓▓░░░          │
│ Белок     95 / 150 г        │
│          ▓▓▓▓▓▓░░░          │
│ [+ Еда]        [+ Вес]      │
└─────────────────────────────┘
```

Карточка дня меняется по ситуации:

| Ситуация | Карточка |
|---|---|
| День тренировки | Тренировка, кнопка «Начать» |
| День отдыха | «Сегодня отдых», совет погулять 20–30 минут, следующая тренировка |
| Пропуск от 5 дней | **«С возвращением!»** Облегчённая тренировка на 20 минут или обычная на выбор |
| Утро после тренировки | Короткий вопрос «Как самочувствие после вчерашнего?» (см. 4.7) |
| Нет разрешения после стоп-экрана | Напоминание о подтверждении от врача |

## 3. Программа

### 3.1 Моя программа
- Название программы, текущая неделя (например «Неделя 3 из 12»).
- Метка, если идёт неделя техники.
- Тренировки A и B со списками упражнений и подходов.
- План недели: какая тренировка в какой день.
- Кнопка «Сменить программу».

### 3.2 Каталог программ
- Карточки программ: «Старт», «Мало времени», «Возвращение», «Только тренажёры», «Бережная к спине», «Только гантели». На каждой написано, для кого она, сколько раз в неделю и сколько минут.
- Рекомендованная AI отмечена.
- Нажатие открывает описание программы и кнопку «Выбрать».
- При смене: «История весов сохранится».

### 3.3 Библиотека упражнений
- Поиск и фильтры: группа мышц, оборудование, «бережно к спине».
- Список: название, иконка оборудования, отметка 🟢.

### 3.4 Карточка упражнения
- Видео с YouTube.
- 2–3 подсказки по технике и частые ошибки.
- Какие мышцы работают.
- Чем заменить.
- Мой прогресс: график рабочего веса и лучший подход.

## 4. Тренировка

### 4.1 Отметка самочувствия
Нижняя шторка перед началом тренировки, 4 быстрых вопроса:
1. Самочувствие: 😫 😐 🙂 💪
2. Сон: плохо / нормально / хорошо
3. Боль сейчас: 0–10. Если больше 0, отметить где.
4. Время: как в плане / меньше (30 мин)

Итог: «План как обычно» или «План изменён: −1 подход, жим ногами вместо приседа». Кнопки «Ок» и «Хочу по плану».
Если боль 7 и выше, тренировка не начинается. Приложение предлагает отдых или лёгкую прогулку и советует обратиться к врачу, если боль не проходит.

### 4.2 Обзор тренировки
- Список упражнений, примерное время, нужное оборудование.
- Кнопка «Начать».

### 4.3 Экран упражнения

```
┌─────────────────────────────┐
│ 2/6  Тяга горизонт. блока   │
│ ┌─────────────────────────┐ │
│ │       ▶ видео           │ │
│ └─────────────────────────┘ │
│ • Спина ровная, грудь вперёд│
│ • Тяни локтями, не руками   │
│                             │
│ Подход  Вес     Повторы     │
│  1      40 кг   12     ✓    │
│  2      40 кг   11     ✓    │
│  3      40 кг   [10]   ○    │
│ Прошлый раз: 37.5 × 12,12,12│
│                             │
│ [Заменить]        [Больно]  │
│ [ Следующее упражнение → ]  │
└─────────────────────────────┘
```

- Вес и повторы подставлены по правилу прогрессии. Поправить можно колёсиком или кнопками +/−.
- Нажатие ✓ записывает подход и запускает таймер отдыха.
- Если вес вырос, рядом подпись: «+2.5 кг: в прошлый раз все подходы по 12».
- Переход к соседним упражнениям свайпом или через список.

### 4.4 Таймер отдыха
- Круговой таймер 60–120 секунд, в зависимости от упражнения.
- Кнопки «+30 с» и «Пропустить».
- Под таймером следующий подход.
- По окончании вибрация и звук.

### 4.5 «Больно»
Нижняя шторка:
1. Где: схема тела.
2. Как сильно: слабо / заметно / сильно, резко.
3. Результат:
   - слабо → советы по технике и «уменьшить вес на 20%»;
   - заметно → замена упражнения на безопасный аналог;
   - сильно → «Остановить тренировку». Совет приложить холод и не нагружать эту зону. Если не проходит — к врачу.
- Приложение запоминает это, и в следующих тренировках упражнение заменяется автоматически, пока пользователь сам его не вернёт.

### 4.6 Замена упражнения
- Причина: занято / нет оборудования / неудобно / больно.
- 2–3 варианта из библиотеки, подходящий отмечен первым.

### 4.7 Итог тренировки
- Время, объём (тонны), выполнено подходов.
- Рекорды: «Новый лучший результат: жим ногами 80 × 12».
- Боль после тренировки: 0–10.
- Как было: легко / нормально / тяжело. Это нужно для подстройки нагрузки.
- Обновлённая неделя: «Неделя: 3 из 3 ✓».
- Если это было возвращение, отдельное поздравление: «Возвращение №5».

**Утром следующего дня** на главной (см. 2) короткий вопрос о самочувствии работает как светофор:
- 🟢 прошло → всё как обычно;
- 🟡 немного болит → следующая тренировка облегчается;
- 🔴 сильно болит или отдаёт в руку/ногу → совет обратиться к врачу, тренировки на паузе до подтверждения.

## 5. Питание

### 5.1 День
- Два кольца: калории и белок, цель и сколько съедено.
- Приёмы пищи: завтрак, обед, ужин, перекусы, с суммой по каждому.
- Кнопка «+ Еда».
- Переход на другие дни стрелками.

### 5.2 Добавить еду
Три вкладки:
1. **Текстом**: «гречка с курицей, большая тарелка». AI возвращает список продуктов с примерными граммами, калориями и белком. Всё можно поправить перед сохранением. Подпись: «Оценка примерная».
2. **Частые**: блюда, которые пользователь уже вносил, добавляются в одно касание.
3. **Шаблоны**: готовые наборы, например «мой обычный завтрак».

### 5.3 Вес
- Ввод веса (лучше утром).
- График: точки по дням и линия среднего за неделю.
- Изменение за неделю и за месяц по среднему.
- Если вес падает быстрее 1% в неделю, приложение мягко советует добавить немного еды.

## 6. Прогресс

### 6.1 Обзор
- **Возвращения**: общий счётчик и история («после паузы 6 дней вернулся 12 марта»).
- Тренировки по неделям: столбики с отметками недель, где выполнена цель.
- Вес: линия среднего за неделю.
- Сила: топ-3 упражнения, рост рабочего веса с начала.

### 6.2 Недельный итог (AI)
Появляется раз в неделю, в понедельник:
- 3–5 предложений: что получилось, что не очень.
- Один конкретный совет на неделю, например «Добавь 20 г белка на завтрак».
- Кнопки «Понятно» и «Обсудить». Вторая открывает короткий чат с вопросом по итогу.

## 7. Друзья

### 7.1 Список
- Каждый друг: имя, аватар, кружки недели (●●○), возвращения, когда тренировался последний раз.
- Кнопка **«Пинок» 👟**: не чаще раза в день одному другу.
- **Весов на штанге и рейтинга здесь нет.**

### 7.2 Пригласить
- Ссылка-приглашение, кнопка «Поделиться».

### 7.3 Входящие
- «Сергей пнул тебя 👟», «Андрей вернулся после паузы — поддержи».
- Значок на вкладке «Друзья». Push-уведомления появятся позже.

---

## 8. Профиль и настройки

- Данные: возраст, рост, активность. Цель питания, кнопка «Пересчитать цели».
- Шаг веса в зале: 1 / 2.5 / 5 кг.
- Язык RU / EN.
- Здоровье: изменить ответы анкеты и отметки боли.
- Видимость для друзей: показывать или скрывать мою активность.
- Экспорт данных (JSON/CSV) и «Удалить аккаунт».
- Дисклеймер: «Приложение не ставит диагнозов и не заменяет врача».
- Выход.

## 9. Особые состояния

| Состояние | Что показываем |
|---|---|
| Нет интернета | Тренировка работает офлайн и синхронизируется потом. AI-функции на паузе с подписью «нужен интернет» |
| AI не ответил | Тренировка по плану без подстройки. Еду можно внести вручную |
| Видео не загрузилось | Подсказки текстом остаются, кнопка «Открыть в YouTube» |
| Первый день | Пустые графики с подписью «Здесь появится твой прогресс после первой тренировки» |
| Нет друзей | Иллюстрация и кнопка «Пригласить» |
