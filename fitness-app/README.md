# Orléans Fitness

Веб-приложение (PWA) для новичков в зале. Концепт — [CONCEPT.md](CONCEPT.md), экраны — [SCREENS.md](SCREENS.md).

## Что уже есть (каркас)

- Вход: пока локальный режим («Продолжить на этом устройстве»). Вход через Google и email подключится после настройки Supabase.
- Анкета из 8 шагов с проверкой ввода.
- Проверка здоровья и стоп-экран «Сначала — к врачу».
- Рекомендация программы (по правилам) и цели по калориям и белку.
- Главная «Сегодня»: цель недели, счётчик возвращений, карточка дня (тренировка / отдых / «С возвращением!» / пауза по здоровью / сделано), утренний светофор, питание вкратце, ввод веса.
- Профиль: язык RU/EN, выход, удаление данных.
- Остальные вкладки — заглушки.
- Работает офлайн (service worker), светлая и тёмная тема.

## Запуск локально

Сборки нет, нужен только статический сервер:

```sh
python3 -m http.server 8000
# открыть http://localhost:8000/fitness-app/
```

На GitHub Pages приложение будет по адресу `https://ddfedotov-droid.github.io/fitness-app/`.

## Структура

```
fitness-app/
  index.html, manifest.webmanifest, sw.js, icon.svg
  css/app.css
  js/
    app.js          роутер и проверки «куда пускать»
    config.js       адреса Supabase и AI-воркера (пока пустые)
    store.js        состояние в localStorage
    auth.js         вход (локальный / Supabase)
    i18n.js         переводы RU/EN
    data/           библиотека упражнений, программы
    logic/          питание, проверка здоровья, рекомендация, логика «Сегодня»
    screens/        экраны
```
