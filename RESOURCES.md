# Ресурсы: стратегия операционных данных в клинических исследованиях

## Knowledge

- [AACT — база ClinicalTrials.gov в виде SQL-таблиц (CTTI)](https://aact.ctti-clinicaltrials.org/)
  Бесплатная реляционная копия всего реестра ClinicalTrials.gov, обновляется ежедневно; есть облачный доступ и снимки для скачивания. Use for: все практические SQL-задания и проект витрины.
- [Snowflake: Zero to Snowflake in 90 Minutes (виртуальная лаборатория)](https://www.snowflake.com/en/webinars/virtual-hands-on-lab/zero-to-snowflake-in-90-minutes-2026-11-25/)
  Официальный пошаговый старт в Snowflake на бесплатном триале. Use for: модуль 1, первое знакомство с платформой.
- [ICH E6(R3) Good Clinical Practice — финальная консолидированная версия (ICH)](https://database.ich.org/sites/default/files/ICH%20E6%28R3%29_Step4_FinalConsolidatedGuideline_2026_0616_.pdf)
  Первоисточник по GCP; риск-ориентированное управление качеством, critical-to-quality факторы, раздел data governance. Use for: модуль 2 (RBQM, KRI/QTL) и модуль 4 (governance).
- [FDA: E6(R3) Good Clinical Practice — страница руководства](https://www.fda.gov/regulatory-information/search-fda-guidance-documents/e6r3-good-clinical-practice-gcp)
  Позиция FDA по E6(R3). Use for: регуляторный контекст США.
- [DAMA: курс и экзамен Data Management Fundamentals (CDMP)](https://cdmpcatalog.dama.org/courses/edw19-fundamentals)
  Официальная страница экзамена CDMP Associate; 14 областей знаний DMBOK V2. Use for: модуль 4, подготовка к сертификату.
- [Snowflake Cortex Analyst — документация](https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-analyst)
  Text-to-SQL поверх семантической модели в Snowflake. Use for: модуль 5, демо-проект.

## Wisdom (Communities)

- [PHUSE](https://phuse.global/)
  Некоммерческое сообщество специалистов по данным в фарме; рабочие группы, конференции. Use for: обратная связь по портфолио, нетворкинг.
- [SCDM — Society for Clinical Data Management](https://scdm.org/)
  Профессиональное сообщество клинического data management. Use for: операционные данные, RBQM, тренды.
- [DIA](https://www.diaglobal.org/)
  Крупное отраслевое сообщество по разработке лекарств. Use for: стратегический уровень, люди из R&D Data Office.
