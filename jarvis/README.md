# Джарвис

Голосовой ассистент в браузере. Страница: https://ddfedotov-droid.github.io/jarvis/

- Скажите «Джарвис, …» и задайте вопрос. Если сказать просто «Джарвис», он пискнет и будет ждать следующую фразу.
- После ответа около 7 секунд можно продолжать разговор без слова «Джарвис».
- 🎙 — сказать одну фразу без слова-активатора. Нажатие на круг во время ответа прерывает его.
- 📎 или перетаскивание — прикрепить PDF, фото или текстовые файлы к следующему вопросу.

Ответы даёт Claude (модель `claude-opus-5-5`) через API с вашим личным ключом из console.anthropic.com.
Ключ, настройки и история разговора хранятся только в этом браузере (localStorage). PDF и картинки
в историю не сохраняются: после перезагрузки страницы Джарвис помнит только их названия.

Распознавание и озвучка речи сделаны средствами браузера (Web Speech API). Лучше всего работает в
Chrome на компьютере и Android. В Safari на iPhone работает, но постоянное ожидание слова «Джарвис»
там менее надёжно. Страница слушает только пока открыта вкладка.
