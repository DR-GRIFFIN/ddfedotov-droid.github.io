# Стартовая точка: клинический домен есть, техника — с нуля

Пользователь сообщил, что работает с клиническими исследованиями и с данными, но SQL, Python/R, ML и облачные
платформы знает на начальном уровне. Цель — Director-роль в стратегии операционных данных AZ.

**Evidence**: самооценка в интервью (ноябрь 2026).

**Implications**: клинические понятия (визит, центр, набор пациентов, мониторинг) не объяснять с нуля — использовать
их как опору для технических концепций. SQL и архитектуру данных начинать с самых основ. Глубину клинических
знаний (CTMS/EDC/RBQM) проверить в первых уроках модуля 2, а не предполагать.
